# /ultrathink-track

The argument is `off`, `on`, or `status`. With no argument, use `status`.

- `off`: remember, for this conversation, that no Linear or Notion rows are created. Planning continues.
- `on`: remember, for this conversation, that rows may be created when Linear or Notion tools are already connected. Planning continues.
- `status`: say which of those this conversation remembers. On is the default.

Do not plan this command. Confirm in one line. This conversation is the only place the preference lives. Do not write a file, do not run a hook, and do not run a planner.
