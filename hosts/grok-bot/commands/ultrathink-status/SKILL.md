# /ultrathink-status

Report what this conversation remembers, and nothing else:

- Planning: on or off. On is the default until `/ultrathink-off`.
- Next message: skipping once, or not.
- Tracker rows: on or off. On is the default until `/ultrathink-track off`. On means rows may be created only when Linear or Notion tools are already connected.

Do not plan this command. Do not invent an engine route, a config file, or a directory. Do not write a file, do not run a hook, and do not run a planner.
