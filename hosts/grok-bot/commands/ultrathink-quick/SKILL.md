# /ultrathink-quick

Everything after the command is the message. Answer this one message directly. Do not plan it, do not build a graph, and do not create tracker rows. With no message, reply: `Usage: /ultrathink-quick <message>`.

The skip is only this message in this conversation. Do not write a file, do not run a hook, and do not run a planner.
